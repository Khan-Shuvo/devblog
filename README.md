# DevBlog - A Modern Developer Blog Platform

DevBlog is a clean, fast, and SEO-friendly blog application designed for developers to share their knowledge. Built with the latest technologies like Next.js, TypeScript, and Tailwind CSS.

## 🚀 Features

- **Modern UI/UX:** Clean design focusing on readability.
- **Fast Performance:** Server-side rendering and optimized images using Next.js.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.
- **Dark Mode Support:** Easy on the eyes for late-night reading.
- **Dynamic Routing:** Individual pages for every blog post.
- **Type Safety:** Built with TypeScript for a robust development experience.

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Deployment:** [Vercel](https://vercel.com/)
- **Icons:** Lucide React / React Icons
